🔐 Acesso e Autentificação 🔐

Como faço para acessar o sistema interno da Via Light?

Para entrar no sistema, acesse a página inicial, clique na opção Login no menu superior direito, insira o seu e-mail corporativo e senha nos campos correspondentes e clique no botão Entrar.

O botão "Entrar" não está avançando de página. O que pode ser?

O formulário de login utiliza uma verificação de segurança local. Certifique-se de que o e-mail foi digitado no formato correto e que nenhum campo obrigatório ficou em branco. Se o problema persistir, contate a equipe de TI.

Esqueci minha senha. O quê fazer?

Contate um dos membros da equipe de TI do website e explique a situação. A equipe ira analisar sua situação e encaminhar um reset para sua senha.

👥 Gerenciamento e Cadastro de Funcionários 👥

Como realizo o cadastro de um novo colaborador no sistema?

Acesse a página de Cadastro de Funcionários. Preencha rigorosamente todos os campos obrigatórios: ID Funcionário, Nome, Email, Telefone, Turno, Cargo, Setor, Endereço e Data de Nascimento. Após preencher, clique no botão Cadastrar para enviar os dados ao servidor.

Como posso atualizar os dados de um funcionário que mudou de cargo ou setor?

No mesmo formulário de cadastro, insira o ID do Funcionário correspondente e preencha os campos que sofreram alterações (como Turno, Cargo ou Setor). Em seguida, clique no botão Atualizar para salvar as modificações no banco de dados.

Qual é o procedimento para excluir um funcionário do sistema?

Insira o ID do Funcionário que deseja remover e clique no botão Excluir. O sistema abrirá uma janela pop-up perguntando: "Tem certeza que deseja excluir?". Clique em Confirmar/OK para validar a operação.

🗺️ Navegação Geral 🗺️

Como faço para retornar ao painel de controle principal (Dashboard)?

Sempre que estiver na tela de gerenciamento de funcionários e precisar retornar ao painel central, basta clicar no link Voltar localizado no lado direito do cabeçalho da página.

Como faço para retornar a tela inicial?

Perceba que no canto superior esquerdo da página, bem no cabeçalho, está presente o nome da empresa juntamente a logo. Simplesmente clique nesta parte para ser redirecionado à página inicial.
